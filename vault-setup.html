1TEAR Vault Setup

One-time page. It creates a vault account with no access keys, registers it with the 1TEAR token, then checks the result on-chain. Every step needs your approval inside your wallet.

Before you start

The vault will be a sub-account of whichever wallet connects here. Once created it has no keys, so nobody can ever move anything sent to it, and the NEAR attached to create it is locked too (about 0.01 NEAR). This cannot be undone.

1. Connect the wallet that will create it

Not connected.

2. Name the vault

Type a short name. It becomes name.your-account.near

To confirm, type the full vault name again:

3. Create the vault

Sends one transaction: create the account and attach 0.01 NEAR for its storage. It adds no keys.


  


  

    
4. Register it with 1TEAR

    
Lets the vault receive 1TEAR. The deposit is read live from the token contract and shown before you approve.
